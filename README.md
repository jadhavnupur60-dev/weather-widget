# 🌤️ Weather Widget

A simple and responsive Weather Widget that displays the current weather information for any city using the OpenWeatherMap API.

## 📌 Project Description

The Weather Widget allows users to enter a city name and view its current weather conditions, including temperature, weather description, feels-like temperature, humidity, and wind speed.

## ✨ Features

- Search weather by city name
- Display current temperature in Celsius
- Show weather description and icon
- Display feels-like temperature
- Show humidity and wind speed
- Responsive design for mobile and desktop
- Input validation and error messages
- Accessible status messages

## 🛠️ Technologies Used

- HTML5 – Structure of the webpage
- CSS3 – Styling and responsive layout
- JavaScript – Weather API integration and functionality
- OpenWeatherMap API – Weather data

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the **Live Server** extension if it is not already installed.
4. Right-click `index.html` and select **Open with Live Server**.
5. Enter your OpenWeatherMap API key in the API Key field.
6. Enter a city name, such as Pune.
7. Click **Get Weather** to view the results.

## 🔑 API Setup

1. Create an account at [OpenWeatherMap](https://openweathermap.org/).
2. Generate an API key from your account.
3. Enter the key into the API Key field on the webpage.
